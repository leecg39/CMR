# 검증 결과

최근 검증일: 2026-10-01. 합성 데이터와 로컬 PostgreSQL 17.11로 실행했습니다. 앞선 QA는 Node.js 22.23.1, 아래 오토 리서치는 Node.js 25.4.0 환경입니다. 서버 기록·고객사 격리는 [PoC 결과](POC.md), 출시 조건은 [제한 출시 관문](LIMITED_RELEASE.md)을 참고하세요.

## 발송 판단 오토 리서치 (2026-10-01)

고정 평가와 3회 실험으로 마케팅 허용 판단의 SQL 호출을 **12회에서 6회로 줄였습니다**. 트랜잭션 설정·잠금·커밋의 고정 4회는 제외한 수치입니다. 각 실험에서 의미 검증 20개, 기존 테스트 63개, TypeScript 검사·빌드가 통과했습니다. 마지막 실제 HTTP·DB PoC 10개도 통과했고 임시 DB·역할을 정리했습니다.

로컬 합성 데이터 100건·동시성 5를 5회 측정한 p95 중앙값은 기준 8.120 ms, 최종 별도 확인 6.231 ms였습니다. 기준 재측정은 7.418 ms와 7.065 ms로 환경 편차가 있으므로 운영 SLA를 뜻하지 않습니다. 평가와 기존 테스트는 해시로 동결하고 변경하지 않았습니다. 각 가설·반복 측정·유지 기준·원본은 [오토 리서치 보고서](../artifacts/autoresearch/2026-10-01/report.md)를 참고하세요.

## 후속 QA (2026-10-01)

Ego Lite에서 관리자 17개 흐름, 모바일 390px의 7개 메뉴, 웹 CMP 16개 시나리오를 다시 확인했습니다. 합성 회원의 예약은 철회로 취소되고 다음 발송은 차단됐으며, 로그아웃 뒤 보호 API는 401을 반환했습니다. 웹 서버 원장의 14개 이벤트와 마지막 두 목적의 REVOKED 상태를 대조했습니다.

증빙 CSV가 PostgreSQL Date 값을 문자열로 바꾸면서 밀리초를 누락하는 문제 1건을 수정했습니다. 실제 다운로드와 JSON 원본의 3개 이벤트를 대조해 두 시각 필드가 모두 일치함을 확인했고 회귀 테스트를 추가했습니다. 최종 자동 테스트는 **63개 통과, 실패·건너뜀 0개**, TypeScript 검사와 빌드도 통과했습니다.

검색 결과 없음 안내와 처리 결과 통지의 내부 코드 표시는 낮은 중요도 문구 개선 2건으로 남았습니다. 상세 재현·수정 전후·화면·실행 범위는 [QA 보고서](../artifacts/qa/2026-10-01/report.md), 자동 검증은 같은 폴더의 `tests-final.log`와 `build-final.log`를 참고하세요. 문자·080 실연동과 파일럿은 사용자 요청대로 제외했습니다.

성능 수치는 로컬 합성 데이터 결과이며 운영 SLA가 아닙니다. 의존성 감사는 검사 시점의 알려진 취약점만 확인합니다.

테스트는 작업 데이터베이스와 분리한 임시 DB를 만들고 비소유자 역할로 실행했습니다. 테넌트 격리, 목적·채널 분리, 멱등성, 과거 이벤트, 철회와 예약 취소, 처리 실패, 시간 경계, 암호화, 서명과 재사용 차단, 삭제·복구·보유기간, MMS 승인 내용과 SOLAPI HTTP 계약을 포함합니다.

웹 선택의 같은 키 재전송은 서버 생성 시각과 원본 이벤트를 유지합니다. 허용 이후 거절은 REVOKED로 기록하며, 철회 뒤 과거 허용을 재전송해도 현재 선택 false를 반환합니다. 회귀 테스트에서 수정 전 재전송이 409로 실패하는 것을 재현한 뒤 수정 후 통과를 확인했습니다.

복구 PoC는 실제 `pg_dump`/`pg_restore` 17.11로 public 테이블 33개를 새 DB에 복원했습니다. AES-256-GCM 암호화, 변조·잘못된 키 거부, 모든 테이블의 행 수·지문 일치, 복원 API의 고객사 격리·원장 불변성과 연락처 키 복구를 확인했습니다. 백업 뒤 발생한 삭제를 서명 이력으로 다시 적용해 예약 취소·광고 차단을 확인했습니다. 수정 전 재내보내기에서 삭제 이력이 누락된 실패는 `artifacts/poc/recovery-repro/http.json`에 있고, 수정 후 이력 보존과 중복 방지까지 통과했습니다. 운영 저장소·별도 백업 매체·실제 키 관리·복제의 복구 훈련은 별도입니다.

## Ego Lite 브라우저 검증

최신 SDK로 별도 PoC API에서 16개 시나리오를 통과했습니다. 기본 선택·재방문 9개, 허용 응답을 실제 서버 접수 후 보류한 연속 허용·철회 3개, 저장·설정 API 연결 실패와 복구 4개입니다. 미선택·거절·철회·연속 선택·API 장애에서 태그 요청은 0건, 분석만 허용 시 분석 1건, 전체 허용 시 분석·광고 각 1건이었습니다.

서버 원장의 이벤트 14건과 마지막 두 목적의 REVOKED 상태를 대조했고 임시 DB·역할을 정리했습니다. 저장 실패는 한국어 안내를 표시하고, 재시도 성공 후 설정을 다시 열면 이전 오류가 지워집니다. 설정 조회 실패는 CONFIG_UNAVAILABLE 이벤트와 기본 거절 신호를 유지합니다. `artifacts/poc/web/browser.json`에는 SDK 지문·요청·실행·선택·신호가, `browser-server-records.json`에는 서버 원본이 있습니다. 화면 3개와 재실행용 `scripts/verify-web.mjs`도 저장했습니다. 초기 수정 전 기록은 `artifacts/poc/latest/`에 남아 있습니다.
