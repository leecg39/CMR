# 이음 — 한국형 동의 운영 SaaS

계획서의 웹 동의 → 회원 동의 → 발송 판단 → 철회 → 증빙 흐름을 실행하는 TypeScript 프로젝트입니다. PostgreSQL을 실제 저장소로 사용하며, 관리자 콘솔·API·워커를 분리했습니다.

## 지금 열기

- 콘솔: **http://127.0.0.1:4310**
- 로그인 화면에서 **데모 워크스페이스 열기**를 선택합니다.
- 가상 테넌트 3개와 합성 회원 100명으로 구성했습니다. 실제 문자는 보내지 않습니다.
- 직접 로그인할 때는 `.local/demo-access.json`에 생성된 계정을 사용합니다. 이 파일과 `.env`는 공유하지 않습니다.
- 서버가 꺼졌으면 `이음 실행.command`를 실행합니다. API와 워커가 함께 시작됩니다.

## 실행

Node.js 22+, PostgreSQL 17+가 필요합니다.

```sh
cd /Users/user01/Desktop/CMP
npm ci
# 최초 한 번: 로컬 PostgreSQL에 별도 DB와 비소유자 역할 생성
npm run setup
npm run seed
npm run build
npm run dev
# 별도 터미널에서 백그라운드 작업 실행
npm run worker
```

현재 컴퓨터에는 setup/seed가 적용되어 있습니다. 다시 실행하면 기존 데이터를 덮어쓰지 않고 중단합니다. 기본 데이터베이스는 `korean_cmp_local`입니다. 다른 DB 이름은 setup 전에 `CMP_DATABASE_NAME`으로 지정합니다. 별도 운영 환경에는 `.env.example`의 값을 설정합니다.

## 구현한 기능

- 테넌트·역할·서버 키·세션 로그인·TOTP 2단계 인증
- 연락처 암호화 및 테넌트별 HMAC, 주체·연락처·목적·사업자 범위 분리
- 문구 버전 게시, 동의 이벤트 원장, 현재 상태, 멱등성, 과거 동의 재전송 방지
- 철회·거부 목록·미실행 예약 취소·외부 전파 outbox의 원자적 갱신
- 발송 요청과 실행 직전 재검사, 주간 정책, 승인 템플릿, 발송량 한도
- 모의 공급자의 정상·거절·접수 전/후 타임아웃, 불명확한 접수의 재발송 방지
- SOLAPI 발송 어댑터, 페이지네이션을 포함한 080 목록 조회, 수신거부 전파
- 좁은 범위의 서명 철회 링크 및 인증된 연동 브리지 이벤트
- 실제 웹 SDK·배너·설정·목적별 태그 로딩, Consent Mode 신호
- 도메인 TXT 확인, HTTP 설치 검사, 격리 브라우저 스캐너 서비스와 egress 프록시
- 처리결과 통지·2년 확인 안내·실패 시 담당자 확인
- JSON/CSV 증빙, 별도 약관 원장, 검증된 식별 연결, CSV 기존 데이터 이관
- 시스템별 삭제 확인, 보존 중지, 승인된 보유기간 후 파기, 삭제 이력 재적용

## 확인 방법

실제 HTTP·DB PoC와 단계별 출시 조건은 [PoC 실행 결과와 재검증](docs/POC.md), [제한 출시 관문](docs/LIMITED_RELEASE.md)에 정리했습니다. `npm run poc`로 작업 DB와 분리된 환경에서 고객사 격리·서버 재시작·기록 불변성을 재검증할 수 있습니다.

1. **발송 통제**에서 동의·증빙이 확인된 회원을 선택하고 발송 전 검사를 실행합니다.
2. 같은 회원에게 미래 시각의 메시지를 예약합니다.
3. **회원 동의 → 상세 보기 → 의사표시 기록**에서 문자 광고 수신을 철회합니다.
4. 예약이 취소되고 다음 검사가 차단되는지 확인합니다.
5. **증빙·정책**에서 회원의 JSON/CSV를 내려받습니다.
6. **웹 동의 → SDK 체험 열기**에서 미선택·부분 허용·전체 허용·거절 후 재방문을 확인합니다.

## 검증

```sh
npm test        # 임시 PostgreSQL DB/역할을 만들어 실제 쿼리로 테스트, 종료 후 해당 DB만 제거
npm run poc:recovery # 합성 전체 DB 암호화 백업·새 DB 복원·삭제 이력 재적용 PoC
npm run build  # TypeScript 검사 + 프런트엔드 프로덕션 빌드
npm audit --omit=dev
```

테스트는 평소 작업 DB를 사용하지 않습니다. `scripts/test.ts`가 별도 `cmp_test_*` DB를 생성합니다. PostgreSQL 생성 권한을 가진 로컬 계정이 필요하며, 실제 테스트는 비소유자 역할로 실행됩니다.

## 운영 전 남은 검증

실제 SOLAPI 계정·등록 발신번호·080 계약·허가된 시험 번호를 통한 실발송은 수행하지 않았습니다. 격리 스캐너의 로컬 컨테이너 실행은 검증했으며, 고객 공개 사이트 검사·고객별 문구와 보유기간 전문 검토·결제 사업자 연결은 남아 있습니다. 코드와 로컬 검증이 운영 출시 승인이나 법적 준수를 보장하지는 않습니다.
